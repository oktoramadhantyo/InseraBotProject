Yang Perlu Disiapkan Besok
1. Buka halaman Insera (ALL TICKET LIST) di browser
- Login seperti biasa
- Pastikan sudah di halaman yang benar
2. Simpan HTML Page 1
- Tekan F12 → tab Elements
- Klik kanan tag <html> paling atas → Copy → Copy outerHTML
- Buka Notepad/VS Code → paste → simpan sebagai page1.html
3. Pindah ke Page 2, simpan HTML Page 2
- Klik tombol halaman 2 di Insera (pagination)
- Ulangi langkah yang sama → simpan sebagai page2.html
4. Catat URL di address bar untuk kedua halaman
- Page 1 URL
- Page 2 URL
- (Ini penting untuk cek parameter pagination yang benar)
5. Screenshot halaman Console (F12 → Console)
- Setelah halaman terbuka, klik "🔄 Sync ke Sheets"
- Screenshot hasil log yang muncul di Console
- Ini akan keliatan error-nya di mana
6. Pastikan Tampermonkey script masih aktif
- Cek ikon Tampermonkey di browser → pastikan script "BotInsera" dalam posisi ON
Ringkasan Cepat
No	Yang Disiapkan	Format
1	HTML page 1	file page1.html
2	HTML page 2	file page2.html
3	URL page 1 & 2	copy-paste dari address bar
4	Screenshot console log	gambar hasil sync
5	Tampermonkey ON	cek ikon extension
